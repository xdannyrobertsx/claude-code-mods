# mods

each mod's own `README.md` (in `mods/<name>/`)
says what it does, how to install it and how to
customize it; it ships with the mod. these docs
cover how each one works inside.

- [memory](memory.md) — how the memory sidebar
  finds the project's memory folder and reads
  each memory's name and description.
- [scratchpad](scratchpad.md) — how the scratchpad
  sidebar finds the session's scratchpad, what it
  keeps in state, and how it stays current.
- [turn-markers](turn-markers.md) — how
  turn-markers decides which prompts and replies
  get a rule, and how it finds a reply's first
  row.
