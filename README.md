# Claude Code Mods

##### these are mods that i personally use - u can use them too if u want :-)

## Mods

| Mod | What it does |
| --- | --- |
| [scratchpad](mods/scratchpad) | A toggleable sidebar showing this session's scratchpad as a live directory tree. |
| [turn-markers](mods/turn-markers) | Colored, labeled rules above your prompts and Claude's replies so they're easy to find when scrolling past verbose tool output. |

## Install

At the prompt of a Claude Code session:

```
/plugin install <mod> --marketplace xdannyrobertsx/claude-code-mods
```

Answer `y` to add the marketplace, then pick a scope.
